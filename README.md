# 듣고 금액 쓰기 (안드로이드 앱)

브로카 실어증 환자를 위한 금액 받아쓰기 연습 앱입니다. 앱이 "구천팔백십 원"을 읽어 주면 숫자 키패드로 `9,810`을 씁니다.

- 하루 문제 수(10·15·20·30개)를 정해서 푸는 일일 퀘스트
- 처음 한 번 실력 확인(8문제) → 14단계 레벨이 자동으로 오르내림
- 틀린 자리를 분석해서 약한 부분(숨은 1, 빈 자리 0, 특정 숫자 소리)을 더 자주 출제
- 레벨 변화·정답률 기록 화면
- **매일 알림**: 정한 시간에 "오늘의 문제를 풀 시간이에요" 알림. 그날 문제를 다 풀면 그날 알림은 울리지 않음

---

## APK 만들기 (GitHub으로 자동 빌드, PC에 따로 설치할 것 없음)

1. GitHub에서 새 저장소를 만듭니다. (예: `listen-money-app`, 비공개도 됨)
2. 이 폴더 전체를 그 저장소의 `main` 브랜치에 올립니다.
   ```bash
   cd listen-money-app
   git init
   git add .
   git commit -m "듣고 금액 쓰기 앱"
   git branch -M main
   git remote add origin https://github.com/<아이디>/listen-money-app.git
   git push -u origin main
   ```
3. 저장소의 **Actions** 탭에서 "APK 빌드"가 도는 걸 확인합니다. 처음엔 5~10분 걸려요.
4. 끝나면 저장소 오른쪽의 **Releases**에 `listen-money-숫자.apk` 파일이 올라옵니다.

이후에 `www/index.html`을 고쳐서 다시 push하면 새 APK가 자동으로 만들어집니다.

## 폰에 설치하기

1. 폰에서 Releases 페이지를 열어 APK를 받습니다.
   - 비공개 저장소라면 폰 브라우저에서 GitHub 로그인이 필요해요. 번거로우면 PC에서 받아서 카카오톡 "나에게 보내기"로 폰에 보내도 됩니다.
2. 받은 APK를 누르면 "출처를 알 수 없는 앱 설치" 허용을 물어봅니다. 허용 후 설치합니다.
   - Play 프로텍트가 "확인되지 않은 앱" 경고를 띄우면 "그래도 설치"를 누르면 됩니다. 직접 만든 앱이라 Play 스토어 등록이 안 돼서 뜨는 경고예요.
3. 앱을 처음 열고 **시작**을 누르면 알림 허용을 물어봅니다. **허용**해야 매일 알림이 옵니다.

### 업데이트할 때
새 APK를 받아서 그대로 설치하면 **기록을 유지한 채 덮어쓰기**됩니다.
앱을 지우고 다시 설치하면 기록이 사라지니 지우지 마세요.

## 꼭 확인할 것

- **한국어 음성**: 폰 설정 → 일반(또는 접근성) → 텍스트 음성 변환(TTS)에서 엔진이 "Google 음성 서비스"이고 한국어 음성이 설치되어 있어야 합니다. 삼성 폰은 삼성 TTS도 한국어가 기본으로 들어 있어요. 소리가 안 나면 여기부터 확인하세요.
- **알림이 안 올 때**: 폰 설정 → 애플리케이션 → 듣고 금액 쓰기 → 알림 허용, 그리고 배터리 → "제한 없음"(또는 "절전 예외")으로 바꿔 주세요. 일부 폰은 배터리 절약 때문에 예약 알림을 늦추거나 막습니다.
- 알림은 앞으로 30일치를 미리 예약해 둡니다. 앱을 열 때마다 다시 채워지니 평소엔 신경 쓸 필요 없어요.
- 알림 시간은 앱 첫 화면 → 설정(보호자용) → 매일 알림에서 바꿉니다. 기본값은 오후 2시.

## 서명 키에 대해

`android/app/listen-money.keystore`는 앱 서명 키입니다. **이 파일을 지우거나 바꾸면** 다음 버전이 기존 앱 위에 설치되지 않아서, 앱을 지우고 다시 깔아야 하고 그때 기록이 사라집니다. 저장소에 그대로 두세요.

## PC에서 직접 빌드하려면 (선택)

Android Studio가 있다면:
```bash
npm install
npx cap sync android
npx cap open android   # Android Studio가 열리면 Run ▶
```
PC에서 빌드한 버전은 버전 번호가 1이라, GitHub에서 받은 더 높은 버전 위에는 설치되지 않을 수 있어요.

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `www/index.html` | 앱 화면과 동작 전부 (이 파일만 고치면 됨) |
| `android/` | 안드로이드 프로젝트 (Capacitor로 생성) |
| `capacitor.config.json` | 앱 이름, 패키지 이름, 알림 아이콘 설정 |
| `.github/workflows/build-apk.yml` | GitHub에서 APK 자동 빌드 |
